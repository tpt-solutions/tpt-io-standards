# Changelog

## [0.1.0] - 2026-08-31

Initial release.

- Core parsing implementation
- SPF (ISO 10303-21) tokenization and parsing
- Entity instance resolution and dangling-reference detection
- Relationship graph construction
- Property set traversal
- Geometry extraction (B-Rep, CSG, tessellated meshes)
- Schema version detection and migration (IFC2X3 / IFC4 / IFC4X3)
- Spatial structure navigation
- Validation support
- Round-trip serialization
- Fuzz targets
- Golden-file corpus
- Property-based tests
- `no_std` + `alloc` + `std` support
