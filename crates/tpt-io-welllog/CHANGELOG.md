# Changelog

## [0.1.0] - 2026-08-31

Initial release.

- Core parsing implementation
- LAS 2.0 / 3.0 ASCII section-based parsing
- LAS 3.0 binary record support
- DLIS (RP66 V1) frame-based parsing
- Depth alignment utilities (common-grid construction, resampling, cross-correlation)
- Validation support
- Round-trip serialization
- Fuzz targets
- Golden-file corpus
- Property-based tests
- `no_std` + `alloc` + `std` support
