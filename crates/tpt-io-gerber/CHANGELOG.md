# Changelog

## [0.1.0] - 2026-08-31

Initial release.

- Core parsing implementation
- Gerber X2 / X3 attribute support
- Aperture definitions and aperture macros
- Graphics operations (flashes, draws, arcs, regions)
- Coordinate format handling (leading/trailing zero suppression)
- Layer polarity handling
- DRC extraction (trace widths, annular rings)
- Excellon drill-file parsing
- Validation support
- Round-trip serialization
- Fuzz targets
- Golden-file corpus
- Property-based tests
- `no_std` + `alloc` + `std` support
